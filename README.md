# Adversarial Vulnerability of Machine-Learning GNSS Spoofing Detectors to Physically Realizable Attacks

## Summary

Machine-learning detectors are increasingly proposed to protect GNSS receivers against
spoofing, yet their behaviour under a deliberate, adaptive adversary is not well
established. We evaluate fourteen detectors (eight classical, six deep) on receiver
observables produced by the open FGI-GSRx software-defined receiver from the Texas
Spoofing Test Battery. Every detector is placed at a common recall-0.95 operating point
and attacked by one shared suite whose decisive element is a gradient-free
decision-based attack; every adversarial example is projected onto the physically
realizable set.
